# LazyR

Данный проект представляет из себя локальное веб-приложение, позволяющее прослушать содержимое сайта или файла. Предоставляется удобный веб-интерфейс с возможностью остановки озвучивания, перемотки, выделения области для чтения. Также можно сохранить историю и прогресс прослушивания.  
Все приложение работает локально, поэтому требует предварительной установки необходимых компонентов, нейросетевых моделей озвучки. 

## Отличительные черты проекта

Запуск и работа крайне нетребовательны к ресурсам, основная цель проекта - запуск на CPU с ограниченным количеством оперативной памяти (GPU не требуется). Для запуска требуется не более 1.5ГБ ОЗУ.  

## Быстрый запуск на Linux

Нужны Python 3.10+ с модулем venv, графическая сессия и доступ в интернет при установке.
Распакуйте архив и откройте терминал в папке `lazyr-app`:

```bash
bash setup.sh
bash start.sh
```

Первый запуск установщика создаёт `.venv`, устанавливает Python-зависимости,
скачивает Chromium и русскую/английскую голосовые модели. Это может занять несколько минут.

Откроется вкладка приложения. Вставьте ссылку и нажмите **«Добавить и слушать»**.
Исходная страница откроется **в другой вкладке того же Chromium**; извлечённый текст
будет озвучиваться через плеер во вкладке приложения. К ней можно вернуться обычным
переключением вкладок. После закрытия всего Chromium приложение завершается;
в терминале его также можно остановить `Ctrl+C`.

Если нужные модели уже скачаны в прежнем проекте, можно использовать их напрямую:

```bash
bash setup.sh --skip-models
bash start.sh --models /полный/путь/к/старому/lazyr/models
```

## Функционал

- История ссылок с заголовками, поиском и фильтрами «В процессе» / «Прослушано».
- Локальная озвучка русского и английского, выбор языка отдельно для каждого фрагмента.
- В главной странице предусмотрена возможность выбора голоса и автоматическое скачивание при его отсутствии.
- Пауза, продолжение, предыдущий/следующий фрагмент и скорость 0.75–2×.
- Стрелки ←/→ переключают предыдущий/следующий фрагмент, как кнопки ↶/↷.
- Полоса прогресса и переход к примерной позиции в статье.
- Панель текста: нажатие на фрагмент запускает чтение с него.
- Сохранение текстов и индивидуального прогресса в SQLite, включая долю текущего аудиофрагмента.
- Продолжение сохранённой статьи после перезапуска, в том числе без сети.
- Подсветка и прокрутка текста в исходной вкладке, открытой при добавлении.
- Паузы на таблицах, формулах, коде и изображениях вместо чтения их содержимого.
- Повторная ссылка не создаёт дубль. Неизменившийся текст сохраняет позицию;
  при изменении текста позиция сбрасывается, чтобы не продолжать с неверного места.
- Удаление статей с подтверждением.

Плавающая панель на вкладке статьи управляет паузой и переходом между фрагментами; пробел тоже ставит чтение на паузу. Вкладка приложения сохраняет библиотеку и общую полосу перемотки.
Кнопка ↗ на карточке открывает исходную страницу в отдельной вкладке.
Для обновления сохранённого текста вставьте ссылку заново.

## Как сохраняется позиция

Текст разбивается на короткие фрагменты примерно до 300 символов.
Хранятся номер фрагмента и доля прослушанного WAV. При продолжении приложение
заново синтезирует этот же фрагмент и перематывает к сохранённой доле.
Во время воспроизведения запись выполняется примерно раз в 3 секунды;
также при паузе, переключении статьи и уходе со страницы.

При аварийном завершении последние несколько секунд могут потеряться.
При штатном закрытии браузера отправка последней позиции тоже зависит от браузера;
периодическая запись ограничивает возможную потерю.
Минуты и общий процент приблизительные: длительность непрослушанных фрагментов
оценивается по числу слов, а не по заранее сгенерированному аудио.

## Архитектура и переносимость

**Python + aiohttp + SQLite → HTML/CSS/JavaScript → Chromium Audio.**
Piper синтезирует WAV на CPU; браузер отвечает за воспроизведение, паузу,
перемотку и изменение скорости.
Playwright управляет отдельными вкладками и позволяет извлекать DOM с сайтов,
для которых обычный fetch из веб-страницы был бы ограничен политикой CORS.

Это приложение с локальным сервером, а не страница, запускаемая двойным щелчком
по HTML. Сервер слушает только `127.0.0.1`, API требует сессионный токен.
История и тексты не отправляются на сервер разработчика. Сами открываемые сайты
по-прежнему делают обычные сетевые запросы и могут использовать собственную аналитику.

Код не привязан к Hyprland, Wayland или конкретному оконному менеджеру.
Основной сценарий — Linux x86_64. Также предусмотрены команды установки и пути
данных для Windows и macOS. Фактическая совместимость зависит от доступности
бинарных пакетов Chromium для ОС и архитектуры.

На Linux браузеру нужны системные библиотеки. Для поддерживаемых Debian/Ubuntu
при сообщении о недостающих библиотеках используйте из активной среды:

```bash
python -m playwright install-deps chromium
```

Команда может потребовать административных прав. На Arch/Fedora/openSUSE и других
дистрибутивах установите Chromium и его зависимости штатным пакетным менеджером.
Можно явно выбрать системный браузер:

```bash
bash start.sh --browser-executable /usr/bin/chromium
```

Путь зависит от дистрибутива. Совместимость версии системного Chromium с Playwright
нужно проверять на целевой машине. Если интерфейс есть, а звука нет, проверьте
микшер/устройство вывода и воспроизведение аудио самим Chromium.

### Windows (PowerShell)

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe setup.py
.\.venv\Scripts\python.exe app.py
```

Активация среды и изменение ExecutionPolicy не требуются.

### macOS / ручная установка на Linux

```bash
python3 -m venv .venv
.venv/bin/python setup.py
.venv/bin/python app.py
```

### Пути и параметры

```bash
python app.py --port 8877 --data-dir /путь/к/данным --models /путь/к/моделям
```

По умолчанию:

| Данные | Место |
| --- | --- |
| Linux | `$XDG_DATA_HOME/lazyr` или `~/.local/share/lazyr` |
| Windows | `%LOCALAPPDATA%/PageReader` |
| macOS | `~/Library/Application Support/PageReader` |
| Голосовые модели | `models/` рядом с `app.py` |

В каталоге данных находятся `history.sqlite3` и профиль Chromium `browser/`.
Для резервной копии закройте приложение и скопируйте каталог данных.
Не запускайте два экземпляра с одним каталогом данных; для второго укажите другие
`--data-dir` и `--port`. История относится к локальной установке, синхронизации нет.

## Ограничения чтения сайтов

Извлекается доступный DOM основного `article` / `main`, иначе `body`.
Меню, скрытые элементы и сноски исключаются по эвристикам. Сложные языковые смеси,
нестандартная вёрстка и большие SPA могут потребовать доработки разбора.

После загрузки страницы есть ожидание около 1.8 секунд (при первой загрузке - около 5 секунд). Бесконечная прокрутка,
вложенные iframe, текст на картинках/canvas и PDF автоматически не разбираются.
Защиту сайтов, CAPTCHA и платный доступ приложение не обходит.
Если нужен вход, выполните его в открывшейся вкладке Chromium и повторно добавьте
ссылку: профиль сохраняет обычную браузерную сессию.
Неудачно загруженная вкладка остаётся открытой для диагностики/входа.

Переход в той же вкладке автоматически запускает разбор новой страницы и
восстанавливает панель. Для медленных SPA разбор может потребоваться повторить
добавлением ссылки. Ссылки в новых вкладках добавляйте через приложение.
Сохранённый текст доступен независимо от исходной вкладки.
Качество голоса определяется моделями Silero TTS; переключение скорости также меняет
длительность, качество зависит от обработки аудио браузером.

## Структура

```text
app.py           локальный HTTP API, Playwright, очередь синтеза и WAV-кэш
core.py          URL, подготовка фрагментов и SQLite
scanner.js       извлечение DOM, подсветка, прокрутка и панель управления на странице статьи
web/             интерфейс и аудиоплеер
setup.py         кроссплатформенный установщик зависимостей и моделей
setup.sh         установка на Linux/macOS с созданием venv
start.sh         запуск на Linux/macOS
tests/           тесты хранилища, подготовки документа и API
```

SQLite и подготовка документов отделены от транспорта и интерфейса.
Для дальнейшей упаковки в настольное приложение можно сохранить API и плеер,
добавив оболочку/лаунчер, или заменить провайдер синтеза без изменения истории.

## Проверки этой версии

```bash
python -m unittest discover -s tests -v
node --check web/app.js
```

В среде разработки прошли 12 тестов: сохранение после перезапуска, дробная позиция,
дедупликация, изменение текста, завершение/удаление, URL, текстовые и визуальные блоки,
сессионная защита, создание отдельной вкладки и выдача WAV/кэш.
В API-тестах Playwright и синтез подменены тестовыми реализациями: эти тесты
не подтверждают фактическое звучание Piper или запуск графического Chromium.
Синтаксис JavaScript и Python проверен. Служба браузерного предпросмотра в среде
разработки недоступна, поэтому визуальная QA и сквозная проверка настоящих
Piper + Chromium, а также проверки на Linux-дистрибутивах, Windows и macOS
не выполнены. Для ручной проверки используйте CHECKLIST.md.

## Область чтения и паузы

Новые статьи открываются без автозапуска. Нажмите «Область» на странице,
протяните прямоугольник мышью (Esc отменяет выбор). В чтение входят текстовые
и визуальные блоки, пересекающие прямоугольник; текстовый блок берётся целиком.
После выбора доступна кнопка «До конца»: она сохраняет ширину и верхнюю границу
области и расширяет её до текущего конца документа. Затем нажмите ▶.
Во время воспроизведения выбор и расширение заблокированы; сначала поставьте паузу.
На новой странице выбор сбрасывается. Для бесконечной прокрутки конец определяется
только уже загруженным содержимым.

На главной задаются минимум и максимум пауз (0–120 секунд). 
Настройки сохраняются в браузере и применяются к следующим визуальным блокам.
Фрагменты из одной пунктуации пропускаются; пустой результат Piper обрабатывается
корректным коротким WAV без ошибки «channels not specified».


## Локальные файлы

На главной нажмите выбор файла в блоке «Прочитать локальный файл», затем
«Открыть файл». Поддерживаются PDF, TXT, MD, HTML/HTM размером до 64 МБ.
Файл обрабатывается локально и открывается в отдельной вкладке с плеером.
PDF отображается как извлечённый текст по страницам, а не в исходной вёрстке;
сканы без текстового слоя требуют предварительного OCR. Защищённые паролем
PDF нужно предварительно сохранить без пароля. Сложные колонки и формулы
могут извлекаться с нарушением порядка. Лимиты: 1500 страниц и 4 млн символов.
TXT/MD читаются как текст; у HTML извлекается текст без исполнения скриптов.
Кодировки: UTF-8 и Windows-1251.

Копии оригиналов, текстовые представления и имена сохраняются в подкаталоге
`documents/` каталога данных рядом с `history.sqlite3`. История и позиция
сохраняются так же, как для сайтов; исходный файл после импорта можно переместить.
Повторное добавление того же содержимого и типа файла не создаёт дубль.
Удаление записи из истории не удаляет локальную копию файла. Для резервной
копии сохраняйте весь каталог данных.
